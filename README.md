# 14-Day Software Engineering Interview Preparation Plan

This repository contains a comprehensive 14-day end-to-end preparation plan for software engineering interviews covering:
- Data Structures and Algorithms (DSA)
- System Design
- Behavioral Interview Preparation

## 14-Day Schedule

| Day | Focus Area | Deliverables |
|-----|------------|--------------|
| **Day 1-3** | Timed DSA and Code Review | Solve one medium problem daily; narrate complexity and five edge cases |
| **Day 4-6** | OOD and Implementation | Model jigsaw, 2048, and one unfamiliar domain; implement the hardest transition |
| **Day 7-9** | Product and System Design | Design collaboration, permissions, synchronization, and failure recovery |
| **Day 10-11** | Extended Coding | Complete one 75-90 minute implementation |
| **Day 12-13** | Behavioral Stories | Rehearse four stories with decisions, conflict, ownership, and measurable outcomes |
| **Day 14** | Mock Loop | Combine coding, OOD, system design, and project deep dive; review recording |
