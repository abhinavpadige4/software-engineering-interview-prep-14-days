## 14-Day Schedule

| Day | Focus Area | Key Activities | Deliverables |
|-----|------------|----------------|--------------|
| **Day 1-3** | Timed DSA and Code Review | Solve 1 medium LeetCode problem daily, analyze complexity, identify 5 edge cases | 5 DSA problems solved with detailed analysis |
| **Day 4-6** | OOD and Implementation | Object-oriented design, implement jigsaw, 2048, and unfamiliar domain problems | OOD principles applied, 3 implementations completed |
| **Day 7-9** | Product and System Design | Study system design fundamentals, practice design problems | System design concepts mastered, 3 design problems practiced |
| **Day 10-11** | Extended Coding | Complete 75-90 minute coding implementations | 2 extended coding problems solved |
| **Day 12-13** | Behavioral Stories | Develop and rehearse STAR stories for leadership, problem-solving, teamwork, adaptability | 4 behavioral stories prepared using STAR method |
| **Day 14** | Mock Loop | Full mock interview combining all areas, review performance | Mock interview completed, areas for improvement identified |

## Behavioral Preparation

**Document**: [BEHAVIORAL.md](BEHAVIORAL.md)

### STAR Method Framework:
- **Situation**: Context and background
- **Task**: Responsibility and objective  
- **Action**: Specific steps taken (focus on "I")
- **Result**: Quantifiable outcomes and lessons learned

### Question Categories Prepared:
1. **Leadership & Initiative**: Leading projects, taking initiative, motivating teams
2. **Problem Solving & Decision Making**: Complex problems, quick decisions, data analysis
3. **Conflict Resolution & Teamwork**: Disagreements, difficult teammates, feedback handling
4. **Adaptability & Learning**: Learning new tech, handling change, failure recovery
5. **Communication & Influence**: Explaining technical concepts, persuasion, presentations
6. **Time Management & Prioritization**: Multiple deadlines, saying no, managing up, pressure

### Preparation Process:
- **Day 12**: Brainstorm experiences, develop STAR stories for 4 key areas
- **Day 13**: Practice delivery, refine stories, prepare for follow-ups
- **Ongoing**: Mock interviews, feedback incorporation, confidence building

### Power Words & Quantifiers:
- Action verbs for strong descriptions
- Result quantifiers (%, $, time saved, customers served, etc.)
- Specific metrics and measurable outcomes

## Usage Instructions

### For DSA Practice:
1. Navigate to `solutions/` directory
2. Run any solution: `python solutions/001_two_sum.py`
3. Review complexity analysis and approach in each file
4. Practice similar problems on LeetCode

### For System Design:
1. Read SYSTEM_DESIGN.md
2. Study key concepts and architecture patterns
3. Practice designing systems using the framework provided
4. Review recommended resources for deeper learning

### For Behavioral Preparation:
1. Read BEHAVIORAL.md
2. Brainstorm personal experiences for each category
3. Develop STAR stories using the templates
4. Practice delivery with timing (1.5-2 minutes per story)
5. Prepare for follow-up questions
